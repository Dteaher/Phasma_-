# Город Хвостиков — Phasma

Android-игра для детей 7–11 лет по задаче Департамента финансов города Москвы на ЛЦТ. Ребёнок помогает питомцу накопить на мечту, планируя игровые монеты и закрепляя финансовые понятия в заданиях.

## Материалы

- `app/` — исходный Flutter-проект, контент JSON, графика и тесты.
- `release/Tailtown-0.17.apk` — подписанный APK 0.17.0 (versionCode 17) для Android 8.0+.
- `docs/Город-Хвостиков-документация-0.17.pdf` — актуальная конкурсная документация; рядом редактируемый DOCX и Markdown-источник.
- `presentation/Город-Хвостиков-Phasma-0.17.pptx` — итоговая презентация команды.
- `rustore/` — иконка 512×512, 8 скриншотов 9:16, тексты карточки, сведения о данных, черновик политики и лицензии.

## Сборка и проверка

Нужны Flutter 3.47.5, Dart 3.13.4, JDK 17 и Android SDK API 36. Из `app/`:

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Для собственной релизной сборки создайте ключ и `app/android/key.properties` по примеру `key.properties.example`. Текущий приватный ключ не опубликован; для обновления APK в магазине нужен тот же ключ подписи. Готовый подписанный APK находится в `release/`. Приложение не использует сервер или аккаунт.

## Статус

Версия 0.17: 35 автоматизированных теста прошли, анализ кода без ошибок. Подписанный APK ранее был установлен и запущен на Realme RMX5051. Добавлен защищённый раздел взрослого с прогрессом, отключением анимаций, отдельным демо и подтверждаемым сбросом. Ручная оценка предыдущей сборки участником команды приведена в отчёте; версия 0.17 на телефоне ещё не проверена. Для финальной сдачи команда должна записать резервное видео работающего APK до 3 минут и заполнить контакт издателя в материалах RuStore.

Прогресс хранится на устройстве. На новом телефоне игра начинается заново; обновление установленного APK сохраняет прежнюю историю.
