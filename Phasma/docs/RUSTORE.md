# Публикация в RuStore — версия 0.16

Актуальный пакет: `output/rustore-0.16/`. Архив для передачи: `Downloads/Tailtown-RuStore-0.16.zip`.

В пакет входят подписанный APK, иконка, 8 рендеров реального интерфейса 900×1600, тексты карточки и инструкции модератору, описание локального хранения данных, проект политики и уведомления о лицензиях.

## Проверено

- APK 0.16.0, versionCode 16, пакет ru.tailtown.tailtown, Android 8+.
- Подпись RSA 2048 / v2 проверена apksigner. Существующий ключ сохранён для совместимости обновлений.
- zipalign: выравнивание APK, включая параметр страниц 16 КБ, прошло. Это не заменяет запуск на устройстве с размером страниц 16 КБ.
- В релизном APK нет INTERNET и чувствительных разрешений; только собственное разрешение AndroidX.
- Иконка 512×512, снимки 9:16; размеры файлов проверены.
- Рендер и навигация на размере 450×800 прошли отдельный Flutter-тест. Для самой версии ранее прошли 32 теста и статический анализ.
- APK ранее установлен и запущен на Realme RMX5051. Полный ручной сценарий на физическом устройстве не зафиксирован; при подготовке пакета устройство не подключено.
- ZIP проверен через testzip, SHA-256 файлов записаны в verification.json.

## Требуются данные владельца

Издатель и контакт поддержки; окончательный текст политики с правилами работы поддержки и публичная ссылка; аккаунт RuStore и проверка уникальности пакета. Возрастная маркировка и права подтверждаются издателем в консоли. Пакет подготовлен локально, в магазин не отправлен.

## Воспроизведение

```powershell
flutter test --no-pub --dart-define=RUSTORE_SHOTS=true test/screenshots_test.dart
python tools/prepare_rustore.py
```

Сборщик упаковывает существующий APK 0.16 из output/android; не собирает и не публикует приложение. Приватный ключ не включён.
