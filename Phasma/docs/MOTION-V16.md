# Анимации 0.16

- Экраны и карточки появляются за 320 мс; кнопки слегка сжимаются при касании за 130 мс.
- Монетки реагируют на изменение баланса, полосы накоплений заполняются за 500 мс.
- Достижения и исполнение мечты сопровождаются коротким конфетти без блокировки касаний.
- Плавно меняются цвет питомца, освещение комнаты, карточки памяти и клетки маршрута курьера; питомец реагирует на пойманный мяч.
- Системная настройка уменьшения движения и сохранённое отключение анимаций учитываются общими компонентами и сценой питомца.
- При переходе остаётся только один активный экран игры, контроллеры освобождаются при закрытии.
