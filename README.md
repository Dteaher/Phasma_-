# Город Хвостиков

**Игра о деньгах и заботе для детей 7–11 лет. Команда Phasma.**

Проект для хакатона «Лидеры цифровой трансформации» по задаче Департамента финансов города Москвы.

Игрок выбирает питомца, заботится о нём и помогает накопить на мечту. Первая цель — велосипед. Чтобы её достичь, ребёнок планирует бюджет, выполняет задания, сравнивает цены и выбирает между покупкой сейчас и накоплениями. После исполнения мечты можно навещать друга в его доме и начать историю с другим питомцем.

## Что есть в игре

- Питомцы, которых можно кормить и расчёсывать движением пальца.
- Бюджет по категориям «Нужно», «Хочу» и «Коплю», магазин и копилка.
- Учебные задания и мини-игры о покупках, ценах и сдаче.
- Карта города, дома друзей и истории исполненных желаний.
- Игровые часы, смена дня и ночи, анимации и достижения.

Игра работает без интернета, регистрации, рекламы и реальных платежей. Прогресс хранится на устройстве. На новом устройстве без переноса данных игра начинается с начала, а обновление установленной версии сохраняет историю.

## Установка

1. Скачайте APK по ссылке выше на Android-телефон.
2. Откройте файл и при необходимости разрешите установку из выбранного браузера или файлового менеджера.
3. Запустите «Город Хвостиков» и выберите питомца.

## Сборка из исходников

Окружение проекта: Flutter 3.47.5, Dart 3.13.4, JDK 17, Android SDK API 36.

```sh
cd Phasma/app
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Для релизной сборки нужен собственный ключ подписи и файл `android/key.properties`, созданный по [образцу](Phasma/app/android/key.properties.example). Приватный ключ опубликованного APK в репозиторий не включён.

Технологии: Flutter и Dart, Riverpod для состояния игры, Hive для локального сохранения, JSON для учебного контента.
